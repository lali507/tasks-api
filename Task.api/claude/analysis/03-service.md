### FN-GU-01: הרשמה

| | |
|---|---|
| שם הפעולה | הרשמה |
| מטרת הפעולה | יצירת חשבון חדש וכניסה מיידית למערכת |
| שדות מושפעים | User – נוצרת שורה חדשה: Email, DisplayName, PasswordHash, Role = Member, CreatedAt |
| תוכן הפעולה | האורח מזין אימייל, שם תצוגה וסיסמה. המערכת מסירה רווחים מהקצוות ושומרת את האימייל באותיות קטנות. אם אחד השדות אינו עומד בכללים (EN-01, EN-01-R1) – 400 עם פירוט השדות השגויים. אם האימייל כבר קיים – 409 "האימייל כבר רשום". אחרת, הסיסמה נשמרת כ-hash בלבד, התפקיד נקבע Member, והמשתמש נשמר. שכבת ה-API יוצרת טוקן (GN-04) ומחזירה אותו יחד עם DisplayName ו-Role, כך שהמשתמש מחובר מיד. הצלחה – 201. |

- כלל FN-GU-01-R1: אין בדיקה בשרת למשתמש מחובר שנרשם – הוא נרשם כמו אורח. הלקוח אינו מציג מסך הרשמה למשתמש מחובר.
