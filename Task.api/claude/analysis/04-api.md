### GN-03: מבנה תשובת שגיאה
כל שגיאה (400, 401, 403, 404, 409, 500) מוחזרת באותו מבנה – ProblemDetails, הפורמט התקני של ASP.NET Core.

| שדה | סוג | מה מכיל | דוגמה |
|---|---|---|---|
| status | int | קוד התשובה | 409 |
| title | string | הודעה קצרה בעברית, להצגה למשתמש | "המשימה כבר נלקחה" |
| detail | string? | הסבר נוסף, אם יש | null |
| correlationId | string | מזהה הבקשה מהלוג (MW-02) | "a1b2c3..." |
| errors | אובייקט? | רק ב-400 – לכל שדה שגוי רשימת הודעות | { "Email": ["פורמט אימייל לא תקין"] } |

- כלל GN-03-R1: ב-500 – title "אירעה שגיאה", בלי פרטים פנימיים (MW-01).
- כלל GN-03-R2: ב-401 ו-403 שמגיעים מ-Authorization (MW-04) – אותו מבנה, בלי errors.
- כלל GN-03-R3: הלקוח מציג את title; ב-400 מציג את errors ליד כל שדה (SC-00-R5).
- כלל GN-03-R4: הודעות השגיאה שנקבעו בפונקציות (למשל "שם הפרויקט כבר קיים") הן ערך ה-title.

### GN-07: הודעות שגיאה
ערך ה-title בכל תשובת שגיאה (GN-03). כל פונקציה משתמשת בנוסח שבטבלה.

| קוד | מקרה | title |
|---|---|---|
| 400 | שדה לא תקין (כללי) | "הנתונים שנשלחו אינם תקינים" + errors לכל שדה |
| 400 | פרמטר רשימה לא תקין (GN-02) | "פרמטר לא תקין" + errors |
| 400 | פרויקט או תווית בגוף שאינם קיימים | "הנתונים שנשלחו אינם תקינים" + errors.ProjectId / errors.LabelIds |
| 401 | בלי טוקן / טוקן לא תקף או שפג | "נדרשת התחברות" |
| 401 | התחברות שגויה (FN-GU-02) | "אימייל או סיסמה שגויים" |
| 403 | תפקיד לא מורשה | "אין לך הרשאה לפעולה זו" |
| 403 | סימון משימה של משתמש אחר (FN-MB-07) | "רק מי שלקח יכול לסמן" |
| 403 | עריכה/מחיקה של Admin (UM-03) | "לא ניתן לשנות משתמש מנהל" |
| 404 | משאב בכתובת לא קיים | "לא נמצא" (אחיד לכל המשאבים) |
| 409 | אימייל כפול (FN-GU-01, FN-AD-16, FN-AD-17) | "האימייל כבר רשום" |
| 409 | שם פרויקט כפול (FN-AD-06, FN-AD-07) | "שם הפרויקט כבר קיים" |
| 409 | שם תווית כפול (FN-AD-12, FN-AD-13) | "שם התווית כבר קיים" |
| 409 | לקיחת משימה שאינה Open / התנגשות בלקיחה (FN-MB-06) | "המשימה כבר נלקחה" |
| 409 | סימון משימה שאינה Taken (FN-MB-07) | "ניתן לסמן רק משימה שנלקחה" |
| 409 | עדכון משימה Done (FN-AD-10) | "לא ניתן לעדכן משימה שהושלמה" |
| 409 | התנגשות בעדכון משימה (FN-AD-10) | "המשימה השתנתה, טען מחדש" |
| 409 | מחיקת משימה Taken (FN-AD-11) | "לא ניתן למחוק משימה שנלקחה" |
| 409 | מחיקת פרויקט עם משימות (FN-AD-08) | "לא ניתן למחוק פרויקט שיש בו משימות" |
| 409 | מחיקת משתמש עם משימה Taken (FN-AD-18) | "למשתמש יש משימה פעילה" |
| 500 | חריגה שלא טופלה (MW-01) | "אירעה שגיאה" |

- כלל GN-07-R1: הודעות לשדות בתוך errors: "שדה חובה", "אורך בין X ל-Y תווים", "פורמט אימייל לא תקין", "הסיסמה חייבת לכלול אות וספרה".
- כלל GN-07-R2: הודעה שמופיעה בפונקציה ובטבלה זו – הנוסח בטבלה זו קובע.
- כלל GN-07-R3: הודעות הלקוח (SC-xx) יכולות להרחיב את הנוסח (למשל "המשימה כבר נלקחה ע"י משתמש אחר"), אך ה-title מהשרת זהה לטבלה.
