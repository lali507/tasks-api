# מסמך ניתוח – אינדקס

מערכת ניהול משימות .NET: Web API, PostgreSQL, לקוח React, פריסה ב-Docker ו-Render. מסמך הניתוח מחולק ל-7 מסמכים לפי שכבות הפיתוח, וכל משימה ב-dev-tasks.md מפנה למסמך אחד.

## מצב
- כל השלבים 1–9 נעולים; 20 העמימויות של האפיון נסגרו; שאלות OP-01 עד OP-06 נסגרו.
- שלב 10 – הפקה: החלוקה ל-7 מסמכים נעולה. גרסה מאוחדת להגשה הופקה ב-Word (מסמך-ניתוח-מערכת.docx). הגרסה המאוחדת אינה כוללת עדיין את תיקון הפריסה.
- תיקון באפיון: נוספו Docker, דחיפה ל-GitHub ופריסה ב-Render – כללים DP-01 עד DP-04 במסמך 5, משימות 46–49. סה"כ 49 משימות.
- שאלה OP-06 נסגרה: השרת והלקוח נפרסים ב-Render כשני שירותים נפרדים עם שתי כתובות (DP-04-R7).

## החלטות מימוש – לשיקול דעת המתכנת
הפריטים הבאים אינם משנים התנהגות חיצונית, ולכן נשארים להחלטת המימוש:
- שמות מחלקות, תיקיות, Controllers ו-Migrations.
- ספריית גיבוב הסיסמה (PasswordHasher של ASP.NET או BCrypt), בתנאי שנשמר hash בלבד.
- מבנה אובייקט התוצאה שה-Service מחזיר (הצלחה, לא נמצא, התנגשות, הרשאה, ולידציה).
- ספריות הלקוח ב-React: ניתוב, שליחת בקשות ועיצוב.
- תוכן נתוני ה-Seed (שמות פרויקטים, משימות ותוויות), בתנאי שהכמויות לפי GN-05.
- הגדרות NLog: מיקום קובץ הלוג ופורמט השורה, בתנאי שהרמות והתוכן לפי GN-06.
- ערכי Issuer ו-Audience של הטוקן, מתוך appsettings (GN-04-R2).
- גרסת תמונת ה-Docker של .NET ושל PostgreSQL, בתנאי שהן תואמות את גרסת הפרויקט.
