### SC-01: התחברות

| | |
|---|---|
| מה מוצג | שדה אימייל, שדה סיסמה (מוסתרת), כפתור "התחברות", קישור "אין לך חשבון? הרשמה" ← SC-02 |
| פעולה | לחיצה על "התחברות" ← POST /api/auth/login (FN-GU-02) |
| בהצלחה (200) | שמירת Token, DisplayName ו-Role; מעבר ל-SC-03; הצגת "שלום, DisplayName" בתפריט |
| הודעות | 400 – הודעה ליד כל שדה שגוי; 401 – "אימייל או סיסמה שגויים"; 500 או אין חיבור – "אירעה שגיאה, נסה שוב" |

- כלל SC-01-R1: בדיקה בסיסית בלקוח לפני שליחה – שדות חובה ופורמט אימייל; הבדיקה הקובעת היא בשרת.
- כלל SC-01-R2: הטוקן נשמר ב-localStorage, כך שרענון הדף לא מנתק. כפתור "התנתקות" בתפריט מוחק אותו וחוזר ל-SC-01.
- כלל SC-01-R3: כל תשובת 401 מהשרת, בכל מסך, מנתקת ומחזירה ל-SC-01 (טוקן שפג או משתמש שנמחק – UM-07).
- כלל SC-01-R4: כתובות האימות – POST /api/auth/login (FN-GU-02) ו-POST /api/auth/register (FN-GU-01).

### SC-02: הרשמה

| | |
|---|---|
| מה מוצג | שדות אימייל, שם תצוגה, סיסמה, אימות סיסמה; כפתור "הרשמה"; קישור "יש לך חשבון? התחברות" ← SC-01; הסבר קצר על כללי הסיסמה (8–64 תווים, אות וספרה) |

- כלל SC-02-R1: שדה "אימות סיסמה" נבדק בלקוח בלבד ואינו נשלח לשרת; אי-התאמה ← "הסיסמאות אינן זהות", בלי שליחה.
- כלל SC-02-R2: משתמש מחובר אינו רואה את המסך (FN-GU-01-R1); ניסיון להגיע אליו ← מעבר ל-SC-03.

### SC-03: רשימת משימות

| | |
|---|---|
| מה מוצג | סינון לפי סטטוס ולפי פרויקט; כרטיס לכל משימה: כותרת, פרויקט, סטטוס, מי לקח ("משתמש שנמחק" כשהשדה ריק ב-Done), תוויות, תאריך יצירה; ניווט בין עמודים ("עמוד 2 מתוך 3") |
| טעינה | GET /api/tasks עם page, pageSize, status, projectId (FN-MB-03); לרשימות הבחירה: GET /api/projects ו-GET /api/labels |
| פעולות Member | "קחי משימה" – רק במשימה Open ← PUT /api/tasks/{id}/assignee (FN-MB-06) |
| פעולות Admin | "משימה חדשה" ← טופס (כותרת, תיאור, פרויקט, בחירת תוויות) ← POST /api/tasks; "עריכה" – רק ב-Open או Taken ← PUT /api/tasks/{id}; "מחיקה" – רק ב-Open או Done ← DELETE /api/tasks/{id} |
| הודעות | לקיחה: 200 – "המשימה נלקחה"; 409 – "המשימה כבר נלקחה ע"י משתמש אחר" והרשימה מתרעננת; 404 – "המשימה כבר לא קיימת". טופס: 400 – ליד כל שדה; 409 בעריכה – "המשימה השתנתה, טען מחדש" או "לא ניתן לעדכן משימה שהושלמה". מחיקה: 409 – "לא ניתן למחוק משימה שנלקחה" |
